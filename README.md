# PhishGuard - Phishing URL Detection System

An educational cybersecurity project that uses Machine Learning
to analyze URL features and flag potentially suspicious links.

## Features
- URL analysis through a Flask web application
- Random Forest classification model
- Responsive cybersecurity dashboard
- URL validation and result display

## Technologies Used
- Python
- Flask
- Pandas
- Scikit-learn
- HTML and CSS

## Installation

1. Clone or download this repository.
2. Install dependencies:

   pip install -r requirements.txt

3. Train the illustrative model:

   python train_model.py

4. Start the application:

   python app.py

5. Open http://127.0.0.1:5000 in your browser.

## Important Note
This is an educational prototype trained on a small illustrative
dataset. Its predictions are not reliable proof that a URL is safe
or malicious. A real deployment requires a properly labelled,
representative dataset and additional security testing.
